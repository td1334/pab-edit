# pab-edit v1.8

Texteditor programmiert mit PABasic für den C64

Features

CTRL + I INSERT LINE       
CTRL + D DELETE LINE
CTRL + B CLR LINE TO BEGIN 
CTRL + E CLR LINE TO END

CTRL + N NEXT PAGE         
CTRL + P PREVIOUS PAGE
CTRL + L LOAD TEXT         
CTRL + S SAVE TEXT
CTRL + 1 CHG DRIVE NUMBER  
CTRL + 3 CHG FILE TYP
CTRL + 4 SHOW DIRECTORY    
CTRL + 5 CHG FONT UC/LC
CTRL + R RESTART EDITOR    
CTRL + U INSERT UMLAUTS
CTRL + C CONFIGURATION     
CTRL + H HELP PAGE


CTRL + SHIFT + M MARK START/END    
CTRL + SHIFT + U CLEAR MARK
CTRL + SHIFT + C COPY MARK TEXT    
CTRL + SHIFT + D DELETE MARK TEXT
CTRL + SHIFT + L LOAD CONFIG       
CTRL + SHIFT + S SAVE CONFIG
CTRL + SHIFT + N NEXT WORD         
CTRL + SHIFT + P PREVIOUS WORD
CTRL + SHIFT + I CHG OVERWR/INSERT


CTRL + COMMODORE + N NEW TEXT
CTRL + COMMODORE + Q QUIT EDITOR
